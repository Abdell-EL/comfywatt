# Data

The ROBOD dataset is not included in this repository.

Download the `Data/` folder from the [ROBOD repository](https://github.com/ideas-lab-nus/robod) (or from [figshare](https://doi.org/10.6084/m9.figshare.19234530.v3)) and put the five files here:

```
data/robod/combined_Room1.csv
data/robod/combined_Room2.csv
data/robod/combined_Room3.csv
data/robod/combined_Room4.csv
data/robod/combined_Room5.csv
```
